My original website is:
https://blog.timenoe.com/

I have connected my self-hosted WordPress account to Lovable.

For this project, WordPress must remain my CMS and source of truth.

IMPORTANT: This is a separate redesign project. My original WordPress website must remain untouched.

Before designing anything, I want you to:

Check whether you can access my WordPress connection.

Retrieve my existing published posts and pages.

Retrieve the available featured images and media.

Identify the different travel destinations and how articles are organised.

Examine the Iceland 2026 travel project in particular.

Identify existing maps, navigation and other interactive features.

Explain how you would connect this content to a completely new frontend.

Technical requirements:

Use WordPress as the content backend.

Read existing content only.

Do not edit, publish or delete WordPress content.

Do not modify the original website.

Do not create duplicate content.

Do not deploy anything to my existing domain.

For now, perform an audit and report your findings. Do not start building yet.
